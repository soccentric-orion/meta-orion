# meta-orion

Yocto layer for **Orion** (STM32MP1), part of the open-source Orion platform from [SoCcentric](https://soccentric.com).

It is used by [Orion-OS](https://github.com/soccentric-orion/Orion-OS), which holds the kas configuration that builds a full image.
